# DevForge Frontend

Consulta el archivo `../README.md` para instrucciones completas de instalación, configuración de Supabase y ejecución local.

Variables requeridas en `.env` (usa `.env.example` como plantilla):
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY` (clave pública publishable/anon, nunca service_role)
- `VITE_API_URL` (por defecto `http://127.0.0.1:8000`)
